# Spraak en Computer Use App — APK-downloads

Dit downloadarchief bevat alleen APK-bestanden en hun SHA-256-controlesom.
De app is een experimentele debugversie. Nederlandse schermvertelling,
lokale taken en optionele AI-planning zijn softwarematig getest.
Hoorbare spraak en geïsoleerde appbediening moeten op de Samsung worden getest.
Geen garantie op een onafhankelijke tweede Android-sessie.

Download de APK bij Releases. Installeer alleen na controle van de versie en hash.
